# ONEPICK[인재추천 포상제도]

2026년 3분기(7.1~9.30) 사내 인재추천 포상제도

## 1. 보상 구성 및 기준

| 구분 | 내용 | 보상 | 비고 |
| --- | --- | --- | --- |
| 추천인 보상금 | 추천인재가 1차면접 합격 시 | 5만원 상품권 (모바일상품권) | 추천 인재가 1차 면접에 합격한 경우 해당월 지급 (인재추천서 품의 완료 이후 지급) |
| | 피추천인 입사 | 팀리드급 이상 : 500만원 / 팀원급(팀리드급 미만) : 300만원 | 피추천인 입사 3개월 이후 지급, 포상금 신청 품의 필수(참조문서: 인재추천 품의서) |

- 추천 시: 추천 인재가 1차면접 합격 시 5만원 상품권 지급(모바일 상품권, 면접 진행월 말일 지급)
- 피추천인 입사 시(입사 후 3개월 경과 시점에 포상금 신청 품의 필수)
  - **팀리드급 이상 : 500만원**
  - **팀원급(팀리드급 미만) : 300만원**

## 2. 지급 원칙 및 유의 사항

- 지급 시기: 해당 월 급여일 지급 (급여일 10일 전 상신 원칙)
- 세금 처리: 과세 후 지급
- 제외 대상: C/Level 이상 경영진은 추천 주체에서 제외

## 추천 양식 및 절차

1. 그리팅 사내추천 공고 페이지 접속 후 순서에 따라 **추천서 작성** 및 **채용서류**(이력서, 포트폴리오 등) **업로드**
   - [그리팅 사내추천 가이드 페이지](https://onepredict.atlassian.net/wiki/x/YIC1vg) 참조
2. 이카운트 품의서 상신
   - 품의서 양식: 그룹웨어 → 기안서작성 → '인재추천서_이름' 검색
   - 인재추천서 결재 라인: 기안자 → 팀리드(결재) → HR 김용민(합의) → HR Lead(합의) → 본부장(결재), 참조: HR Team
   - 첨부할 파일 없음 (그리팅 사내추천 공고에서 추천서 및 채용서류 업로드 완료)
3. 포상금 신청서 상신
   1. 포상금 신청서는 지급월 20일 전까지 올려주시기 바랍니다.
   2. 포상금 신청 시, 인재추천포상금 품의에는 **추천 시 작성하신 인재추천서 품의를 참조문서로 첨부**해야 합니다.
   3. 포상금 신청서 결재 라인: 기안자 → HR 오유미(합의) → HR Lead(합의)
