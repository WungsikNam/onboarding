# 호칭 가이드

## 우리의 전문성을 전하는 [호칭] 언어

| 구분 | 내부 협업 (Internal) | 외부 미팅 (External) |
| --- | --- | --- |
| 핵심 가치 | 수평적 문화와 소통 | 전문성 전달과 신뢰 구축 |
| 권장 호칭 | '구성원의 성함 + 님' | '성함 + 프로(님) / 프로페셔널(님)' 또는 외부 직함이 있을 시, 예) '성함 + 이사님' |
| 적용 사례 | "유미님, 확인 부탁드려요." | "오유미 프로님을 소개합니다." |

- **전문성 강화:** 외부 관계자에게 우리 구성원의 전문 역량과 역할을 명확히 전달합니다.
- **비즈니스 격식:** 공식적인 직함을 통해 파트너사와의 상호 존중 및 비즈니스 매너를 갖춥니다.
- **신뢰도 제고:** 대외적으로 통용되는 호칭 사용 시, 조직의 체계와 전문성을 더 높게 평가받는 효과가 있습니다.
