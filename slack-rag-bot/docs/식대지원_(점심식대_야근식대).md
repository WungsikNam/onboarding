# 식대지원 (점심식대 / 야근식대)

**점심 식대**

1. 지급기준
   * 지급 금액 : 1일 12,000원 (급여일에는 20,000원 지급)
   * 지급 방법 : 식권대장 앱 활용
   * 휴일근로(주말·공휴일) 시에는 개인 법인카드 사용 후 지출결의를 통해 동일한 금액을 지원합니다.
2. 이용안내
   * 사용처 : 회사 근처 식권대장 제휴 식당
   * 사용 시간 : 오전 7시 ~ 오후 3시 (오후 3시 마감, 이후 미사용 금액 자동 소멸)
   * 기본 조건 : 당일 실제 근무 시간 4시간 이상 시 사용 가능
     (예시) 반차/반반차 사용 후 4시간 근무 → 사용 가능 (O)
     (예시) 반차/반반차 사용 후 3시간 근무 → 사용 불가 (X)

**야근 식대**

1. 지급기준
   * 지급 금액 : 1일 12,000원
   * 지급 방법 : 개인 법인카드 사용 후 지출결의 처리
   * 휴일근로(주말·공휴일) 시에는 개인 법인카드 사용 후 지출결의를 통해 동일한 금액을 지원합니다.
2. 이용안내
   * 기본 조건 : 당일 실제 근무 시간 10시간 이상 시 사용 가능
   * 야근 식대 사용 시 저녁 식사 시간은 근태시스템(원티드스페이스) 상 '자리 비움'으로 체크해야 합니다.
   * 당월 사용분 익월 초까지 지출결의서 작성 필수(문의 : finance team)
