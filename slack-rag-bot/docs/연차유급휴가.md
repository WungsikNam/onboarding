# 연차유급휴가

## 연차 생성 및 부여 기준

1. 1년 미만 근속자 부여 방식
   - 입사년도에는 입사일부터 해당 연도 12월 31일까지 1개월 개근 시 1일의 연차를 부여합니다.
   - 해당 연차는 사용 편의를 위해 입사 시 선 부여됩니다.

2. 연차 생성일 및 기본 부여 일수
   - 입사년도 다음 해 1월 1일에 1년차 연차 15일이 일괄 부여됩니다.
   - 해당 15일에는 1년 미만 근속 기간 동안 발생한 연차가 포함됩니다.

3. 퇴사 시 연차 정산
   - 퇴사 시 연차는 입사일 기준으로 재산정하여 정산합니다.
   - 재산정 결과 연차를 초과 사용한 경우 공제되며, 미사용 연차가 발생한 경우 수당으로 지급됩니다.

## 연차 정산 및 소멸 기준

1. 중도 퇴사 시 정산
   - 중도 퇴사 시 사용 연차와 발생 연차를 정산하여 마지막 급여에 반영됩니다.
