# 장기근속휴가(포상)

**근속 연수별 포상 기준**

1. 3년 : one-fresh 휴가 3일 / one-reward 50만원
2. 5년 : one-fresh 휴가 5일 / one-reward 100만원
3. 10년 : one-fresh 휴가 10일 / one-reward 500만원

**휴가 사용 및 관리 규정**

1. 사용 원칙
   * 장기근속휴가는 부여된 일수 단위로 연속 사용을 원칙으로 하며, 분할하여 사용할 수 없습니다.
2. 소진 기한
   * 발생 후 6개월 내 사용해야 하며, 기한 내 미사용 시 자동 소멸됩니다.
3. 신청 기한 및 절차
   * 해당월 20일 전까지 품의서 양식(포상금 신청서_이름) 작성 후 상신해야 합니다.
4. 품의서 결재라인
   * 결재라인 : 기안자 → HR 오유미(합의) → HR Lead(합의)
   * 참조 : HR Team, FN Team, CFO
