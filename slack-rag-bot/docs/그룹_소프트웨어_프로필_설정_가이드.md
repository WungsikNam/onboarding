# 그룹 소프트웨어 프로필 설정 가이드

## [슬랙] 프로필 업데이트

방법: 슬랙 프로필 편집 → 휴대폰 번호 등록 → [이름(영문)/소속] 형식으로 '표시 이름' 변경 → 본인 사진 업데이트

- 표시 이름 예시: 오유미(Youmi.Oh)/HR

## [원티드 스페이스] 프로필 업데이트

방법: 원티드 스페이스 접속 → 내 프로필 → 본인 사진 업로드

## [Atlassian] 프로필 업데이트

(Atlassian 프로필 변경 시 Jira 및 Confluence 프로필 연동)

방법: Atlassian 프로필 > 계정관리 > '프로필사진' 등록 > '공개이름' 변경

(직위, 부서, 조직명 등도 함께 업데이트 해주시면 좋습니다)
