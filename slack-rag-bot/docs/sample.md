# 휴가 신청 가이드

## 연차 신청 방법
연차는 사내 그룹웨어(HR 포털) > 근태관리 > 휴가신청 메뉴에서 신청합니다.
최소 사용 하루 전 오후 6시까지 신청해야 하며, 팀장의 승인이 필요합니다.

## 반차/반반차
반차는 4시간 단위, 반반차는 2시간 단위로 사용할 수 있습니다.
당일 신청은 팀장에게 별도로 슬랙 DM으로 사전 공유 후 신청해야 합니다.

## 병가
병가는 진단서 없이 연 5일까지 사용 가능하며, 5일 초과 시 진단서 제출이 필요합니다.

## 경조사 휴가
- 본인 결혼: 5일
- 자녀 결혼: 1일
- 부모/배우자 사망: 5일
- 조부모/형제자매 사망: 3일

문의사항은 인사팀(#hr-support 채널)으로 연락해 주세요.
