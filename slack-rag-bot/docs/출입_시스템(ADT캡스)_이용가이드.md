# 출입 시스템(ADT캡스) 이용가이드

신규 오피스에서는 **ADT캡스 출입 시스템**을 통해 사무실 출입 및 보안 설정을 관리합니다.
아래 내용을 참고하여 모바일 출입카드를 등록해 주세요.

## 1. 모바일 출입카드 등록 (권장)

편리한 출입을 위해 **모바일 출입카드 등록을 적극 권장**드립니다.

* 첨부된 [출입 모바일 카드 등록 가이드]를 확인하여 개별 등록을 부탁드립니다.
* 등록 완료 후, 출입문 앞에서 모바일 출입카드를 태그하면 문이 자동으로 열립니다.
* **갤럭시(Android)** : 화면만 켠 상태에서 교통카드처럼 태그하면 바로 출입문이 열립니다. (앱을 실행하지 않아도 됩니다.)
* **아이폰(iPhone)** : 패스트파이브 출입 방식과 동일하게, 앱을 실행한 후 태그해야 출입문이 열립니다.

첨부파일: [모바일 출입카드 등록 가이드](https://docs.google.com/presentation/d/1b-B4uuCYu-GJMhYT6WVwenMoKxaN4GlE-ceDLxv1TYU/edit?usp=sharing)

### 지문 등록

원하시는 분에 한하여 별도 안내를 통하여 등록 도와드릴 예정입니다.

## 2. 근태 관리 안내

ADT캡스 시스템은 **출입 관리용으로만 사용**됩니다.

* 출퇴근 기록 및 근태 관리는 기존과 동일하게 **원티드스페이스 앱**을 통해 진행해 주세요.
* 모바일 출입카드 사용 여부와 관계없이 근태 체크는 별도로 진행해야 합니다.

## 3. 출퇴근 시 보안 설정 지침

사무실 보안을 위해 최초 출근자와 최종 퇴근자는 아래 사항을 준수해 주세요.

※ 1층 메인 출입문은 **별도의 경비 설정 없이 카드 태그만으로 출입이 가능**합니다.

### 출근 시

각 층 사무실에 가장 먼저 도착하신 분은 캡스 기기의 **[해제]** 버튼을 누른 뒤 카드를 태그해 주세요.

### 퇴근 시

각 층 사무실에서 마지막으로 퇴근하시는 분은 각 층 출입구에 설치된 캡스 기기에서 **[경비]** 버튼을 누른 뒤 카드를 태그한 후 퇴근해 주세요.

※ 1층 메인 출입문은 별도로 **[경비]** 설정을 하지 않습니다.

---

모바일 카드 등록이나 출입 시스템 이용 중 문제가 발생하거나 도움이 필요하신 경우 HR팀으로 문의해 주세요.
