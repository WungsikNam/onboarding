# 2.6.1 substation Deep dive

## Guardian Substation — 제품 이해 (역기획)

이 문서는 **역기획(Reverse Engineering) 관점**에서 "왜 이 기능이 존재하는가", "왜 이 방식을 선택했는가"를 분석합니다. 현재 개발은 **HOLD 상태**이므로 로드맵보다 Lessons Learned에 집중합니다.

## 1. 제품이 존재하는 이유

### 1.1 해결하는 문제

변압기는 공장·발전소 전력 공급의 핵심 설비다. 한 대가 고장나면 공장 전체가 멈추고, 손실은 수십억~수백억원에 달한다(LG화학 추정 최대 100억원). 변압기는 맞춤 제작 특수 설비라 복구에 수주~수개월이 걸린다.

**기존 방식의 한계**: 정기 점검(6개월~1년 주기)은 점검 사이 고장을 예측할 수 없고, 전문가 오프라인 분석은 시간·비용이 소요되며 주관적이다.

### 1.2 핵심 가치

| 가치 | 설명 | 증거 |
| --- | --- | --- |
| **사전 경보** | 고장 수주~수개월 전 이상 징후 감지 | LG화학: 투자 2,100만원 → 예방 손실 최대 100억원 |
| **ROI 47,500%** | 세계 최고 수준 투자 대비 가치 | LG화학 실제 케이스 (영업 핵심 레퍼런스) |
| **재학습 불필요** | 국제 표준(IEEE/IEC) 기반 → AI 별도 훈련 없음 | 글로벌 확장 용이, 어디서나 즉시 적용 |
| **대규모 관리** | 수십~수백 대를 단일 화면에서 관리 | S-Oil 46대, 롯데케미칼 60대 |

### 1.3 한 줄 요약

> **"변압기 절연유 속 가스를 AI로 분석해, 고장 전에 알려주는 예지보전 플랫폼"**

## 3. 화면별 기능 및 동작

### 화면 1: 메인 대시보드

**목적**: 관리하는 모든 변압기의 건전성 상태를 한눈에 파악

| 기능 | 동작 |
| --- | --- |
| 설비 현황 카드 | 각 변압기 현재 등급(정상/주의/위험) 표시 |
| 알람 배지 | 새로운 이상 감지 시 알림 표시 |
| 통계 요약 | 전체 설비 수, 정상/주의/위험 비율 |
| 빠른 이동 | 카드 클릭 → 해당 설비 상세 화면으로 이동 |

### 화면 2: 설비 상세 화면

**목적**: 특정 변압기의 진단 현황 및 이력 확인

| 영역 | 기능 |
| --- | --- |
| 현재 진단 등급 | 정상/주의/위험 + 근거 가스 항목 표시 |
| 가스 농도 트렌드 | 시계열 그래프로 가스 농도 변화 추이 |
| Duval Triangle | 현재 가스 비율의 고장 유형 위치 시각화 |
| 조치 권고 | 점검 주기 단축 / 즉시 점검 / 운전 중단 권고 |

### 화면 3: DGA 데이터 입력

**목적**: 오프라인 DGA 샘플 측정 결과를 시스템에 등록

| 입력 항목 | 비고 |
| --- | --- |
| 측정일자 | 필수 |
| 각 가스 농도 (H₂, CH₄, C₂H₂, C₂H₄, C₂H₆, CO, CO₂, O₂, N₂) | O₂, N₂ 선택 항목 |
| 측정 기관 | 필수 |
| 변압기 부하율 | 선택 항목 |

**수동 입력 오류 다발 주의**: 고객이 잘못된 값을 입력해 진단 결과가 왜곡되는 케이스가 반복 발생. 입력값 유효성 검증 강화가 백로그에 있음.

### 화면 4: 진단 결과 상세

| 항목 | 내용 |
| --- | --- |
| 건전성 등급 | 정상 / 주의 / 위험 |
| 고장 유형 | 열적 이상 / 방전 이상 / 복합 이상 / 정상 |
| 진단 근거 | 어떤 가스가 기준치를 초과했는지 |
| 추천 조치 | 다음 측정까지의 권고 기간 |
| TDCG | 총 가연성 가스 합산값 및 IEEE 기준 대비 위치 |

### 화면 5: 보고서 자동 생성

| 기능 | 내용 |
| --- | --- |
| 자동 리포트 | 진단 결과 + 그래프 + 권고사항 포함 PDF |
| 해상도 최적화 | Mac/Windows 동일 출력 (v2.3.2에서 80% 개선) |

| 항목 | 내용 |
