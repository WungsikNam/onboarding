# 2.6.2 substation 기술 구조

## Guardian Substation — 기술 이해

개발자·기술 PM이 제품을 구현하고 운영하기 위해 알아야 할 기술 구조를 정리합니다. 현재 개발 **HOLD 상태**이며, 이 문서는 기존 구현 이해와 향후 인수를 위한 레퍼런스입니다.

## 1. 핵심 기술 개념: DGA (Dissolved Gas Analysis)

### 1.1 DGA 원리

변압기 내부에서 이상이 생기면 열이나 방전으로 절연유가 분해되고, 특정 가스가 발생한다. 이 가스를 분석하면 고장 유형과 심각도를 사전에 알 수 있다.

```
변압기 내부 이상 발생
    ↓
절연유 분해 → 가스 생성
    ↓
오프라인 (주기적 샘플 채취) 또는 온라인 (실시간 센서) 측정
    ↓
가디원 서브스테이션이 분석
    ↓
"주의 / 위험" 등급 + 고장 유형 + 조치 권고
```

### 1.2 진단 알고리즘 (국제 표준 기반)

| 알고리즘 | 원리 | 특징 |
| --- | --- | --- |
| **Duval Triangle** | CH₄·C₂H₂·C₂H₄ 3가지 비율로 고장 유형 삼각형 지도 | 시각화가 직관적, 국제적으로 가장 널리 사용 |
| **Rogers Ratio** | 가스 비율(C₂H₂/C₂H₄, CH₄/H₂, C₂H₄/C₂H₆)로 고장 유형 판별 | 정량적 판별, Duval 보완 |
| **IEEE C57.104** | 가스 농도 절대 기준값 (TDCG 포함) | 미국 표준, 한국 고객사 기본 참조 |
| **IEC 60599** | 가스 비율 해석 국제 표준 | 유럽·글로벌 표준 |

**왜 재학습이 필요 없는가?** 위 표준들은 전 세계 수십만 변압기 데이터를 기반으로 수십 년간 검증된 보편 기준이다. 이 기준 자체가 이미 AI 모델의 역할을 한다. 따라서 고객 데이터로 별도 훈련 없이 어디서나 즉시 적용 가능하다.

### 1.3 가스별 의미 및 진단 활용

| 가스 | 화학식 | 고장 유형 신호 | 심각도 |
| --- | --- | --- | --- |
| 수소 | H₂ | 부분방전 — 가장 초기 이상 징후 | 낮음~중간 |
| 아세틸렌 | C₂H₂ | 아크 방전 | **매우 높음 (즉시 조치)** |
| 에틸렌 | C₂H₄ | 고온 열적 이상 | 높음 |
| 메탄 | CH₄ | 저온 열적 이상 | 중간 |
| 일산화탄소 | CO | 고체 절연재(종이) 열화 | 중간 |
| 이산화탄소 | CO₂ | 고체 절연재 열화 | 낮음~중간 |
| TDCG | - | 총 가연성 가스 합산 — 전체 심각도 지표 | IEEE C57.104 레벨 1~4 |

_현재 7가지 가스 지원. 경쟁사 TOA4는 9가지 (O₂, N₂ 추가 지원). IEEE C57.104-2019 표준 적용 시 O₂, N₂ 필수._

## 2. 전체 데이터 흐름

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  현장 (변압기)                                                              │
│  [오프라인 DGA 측정] → 현장 채취 → 분석 기관 → 측정 결과지 수신              │
│  [온라인 DGA 센서]  → 실시간 가스 농도 전송 (현재 미지원, 향후 과제)         │
└───────────────────────────┬─────────────────────────────────────────────────┘
                            │ 담당자가 웹 UI에 수동 입력
                            ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  가디원 서브스테이션 웹 서버 (AWS EKS)                                      │
│  - 입력값 유효성 검증 (COMMON_001, COMMON_002 에러 코드)                    │
│  - API 호출 → AI 진단 엔진                                                  │
└───────────────────────────┬─────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  AI 진단 엔진                                                               │
│  - Duval Triangle 판정 (CH₄·C₂H₂·C₂H₄ 비율 → 고장 유형 좌표)              │
│  - Rogers Ratio 판정                                                        │
│  - IEEE C57.104 기준 초과 가스 식별                                         │
│  - TDCG 계산 (총 가연성 가스 합산)                                          │
│  - 계측 신뢰성 평가                                                         │
└───────────────────────────┬─────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  결과 저장 및 출력                                                          │
│  - 진단 등급 저장 (정상/주의/위험)                                          │
│  - 대시보드 업데이트                                                        │
│  - 이메일 알람 발송 (APScheduler 기반)                                      │
│  - PDF 자동 리포트 생성                                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 인프라 및 배포 구조

### 3.1 배포 환경 4단계

| 환경 | 목적 | URL | 주의 |
| --- | --- | --- | --- |
| **dev** | 기능 개발 | 내부 |  |
| **staging** | QA 수행 전용 | substation-v2.guardione.live | 개발 QA 전용 |
| **demo** | 영업 데모 전용 | [http://demo-substation.guardione.ai](http://demo-substation.guardione.ai) | **고객사 계정 공유 절대 금지** |
| **prod** | 실 고객 운영 | [http://substation.guardione.ai](http://substation.guardione.ai) (추정) | 계약 완료 즉시 계정 생성 필수 |

**한국동서발전 사고 (2024-12-19)**: 계약 후 production 계정 미생성 → staging 서버를 6개월 이상 운영용으로 사용. 계약 완료 즉시 production 계정 생성 체크리스트 확인 필수.

## 6. 운영 이슈 패턴

### 6.1 반복 이슈 유형

| 패턴 | 사례 | 근본 원인 | 해결 방향 |
| --- | --- | --- | --- |
| 수동 입력 오류 | S-Oil 연산 오류, 롯데엠시시 TDCG 문의 | 고객이 잘못된 값 입력 → 진단 왜곡 | 입력 유효성 검증 강화 + 자동화 |
| 운영 서버 관리 부재 | 이메일 발송기 중단, 한국동서발전 계정 사고 | 환경별 운영 체계 미비 | 서버 운영 체크리스트 + 자동 모니터링 |
| 표준·기술 문의 | 롯데엠시시 TDCG 수치 차이, GS파워 IEEE 2019 | 고객 자체 기준과 IEEE 표준 차이 인지 부족 | 고객 교육 자료 체계화 |
