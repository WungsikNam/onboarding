# 이메일 서명 설정 가이드

## 설정방법

- 구글메일 로그인 → 서명 설정 → 서명 '새로 만들기' → 전달받은 양식 활용하여 정보 기입

## 서명 이미지 양식

- [서명 이미지 양식 바로가기](https://docs.google.com/spreadsheets/d/1_4bWk8Kr332dwy6TgfNSukKiauT8HKxdfF14Fo7vPF0/edit?gid=0#gid=0)
- 서명 양식 드래그 시 A1, A2 행을 함께 선택하여 복사 후 구글 전자서명에 정보를 입력해 주시고, 이후 서명 기본값에서 초기 설정을 진행해야 정상적으로 적용되니 참고 부탁드립니다.

## 직급 설정 안내

a. 팀리드: 국문_팀리드 / 영문_Team Lead

b. 구성원(팀원): 국문_프로 / 영문_Professional

- 외부 직급이 필요한 경우: 본부 내 합의된 별도 타이틀 사용 가능
