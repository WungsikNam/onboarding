# 각종 증명서 신청 가이드

증명서 발급이 필요한 경우 그룹웨어 내 품의서 양식을 통해 신청해주시기 바랍니다.
※ [일반증명서] 신청과 [소득증명서] 신청은 각각 별도의 양식으로 구분되어 있으니 해당하는 양식을 선택하여 품의 상신해주시기 바랍니다.

## 신청 방법

1. 그룹웨어 → 품의서 양식에서 '증명서' 검색 후 해당하는 양식 선택
   - 기본 결재라인이 설정되어 있으니 그대로 내용 기입하여 상신해주시면 됩니다.
2. 명판, 직인 등 추가 요청사항이 있을 경우 비고란에 반드시 기입해주시기 바랍니다.
3. 제출처, 용도, 필요 기재사항(영문명, 주민등록번호 등)이 있는 경우 함께 기재해주시기 바랍니다.

## 결재라인

1. 일반 증명서(재직/경력/퇴직): 기안자 → HR 이서영(합의)
2. 소득 증명서(원천징수영수증 등): 기안자 → HR 오유미(합의)
