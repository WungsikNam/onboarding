# 건강검진 (비용 및 복지혜택 안내)

## 건강검진 안내

1. 제휴업체: SCL 사이언스(마이원케어)
2. 이용기간: 3월 16일 ~ 12월 19일
3. 검진센터: 하나로의료재단
   - (강남 1센터) 서울시 강남구 테헤란로 326 아이타워 7~11층(강남)
   - (강남 2센터) 서울시 강남구 언주로 508 상록회관 하나로리더스헬스케어
   - (종로센터) 서울시 종로구 종로 33 그랑서울 1타워 5층(강북)

## 검진 예약방법

1. [https://myonecare.co.kr/onepredict](https://myonecare.co.kr/onepredict) 접속, 임직원 인증 후 예약 진행 (첨부 매뉴얼 참고)
2. 검진지원비용은 30만원으로, 임직원 본인에 한하여 지원됩니다.
3. 결제는 개인 선결제 후 증빙 처리 방식이 아닌, 업체 → 회사(원프레딕트)로 직접 청구되는 방식으로 진행됩니다.

## 기타사항

1. 제휴되지 않은 타 업체를 통한 건강검진은 지원이 불가합니다.
2. 건강검진 관련 문의가 있으실 경우 HR Team으로 문의 부탁드립니다.
3. [마이원케어 사용 매뉴얼(링크)](https://drive.google.com/file/d/15UISRRvMCyRXQBTVFQ2Nqn-pZAENyEI8/view?usp=sharing), 건강검진 항목표(2026)
4. 건강검진 휴가: [건강검진휴가 사용방법은 [Benefit & Culture] 탭 참조](https://onepredict.atlassian.net/wiki/spaces/OS1/pages/3077439558)
